# FNO-Trading-Insights-Dashboard-Excel-
Interactive F&O Trading Insights Dashboard built in Microsoft Excel using Pivot Tables, Pivot Charts, KPIs, and Slicers to analyze trading performance, profit & loss trends, win rate, and entry-hour behavior.
**F&O Trading Insights Dashboard (Excel)**

This project is an interactive Excel dashboard created to analyze F&O trading performance from Apr 2026 to Jul 2026. The dashboard converts raw trade data into meaningful insights through data analysis and visualization.

**Dashboard Highlights**
Total Trades
Net P&L
Winning Trades
Losing Trades
Winning Rate %
Monthly P&L Trend
P&L by Weekday
Profit vs Loss Comparison
P&L by Entry Hour
Monthly Winning vs Losing Trades
**Tools Used**
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
KPI Cards
Data Cleaning
Dashboard Design
**Key Insights**
Identified months with highest losses and profits.
Analyzed weekday-wise trading performance.
Studied the impact of trade entry hour on profitability.
Measured overall trading win rate and consistency.
